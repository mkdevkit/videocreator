# videoeditor

Web / Tauri 剪辑器。时间轴对齐**剪映分类型多轨**（文字 / 调节 / 叠加 / 主视频 / 原声 / 配音 / 音乐 / 音效），不是 Premiere 那种通用 V1、A1。

口播生成画面继续用 [`web2video`](../web2video) / [`script2video`](../script2video)。这边吃视频、音频、图片、字幕文件，时钟是秒/帧，不是 `speech.s(id)`。

预览和导出原则见仓库根 [README · 预览和导出](../README.md#预览和导出)：同一条合成路径（`drawFrame`），字体 SIL OFL 打包，烧录字幕默认关。

```bash
cd videoeditor
npm install
npm run dev        # http://localhost:5175
npm run tauri:dev  # 桌面（需 Rust）
```

建议 **Chrome 或 Edge**。第一期适合短片；叠加轨同时可见建议不超过 2 路。

## 定位

| | 含义 |
| --- | --- |
| 分类型轨 | 剪映模型，不是通用音视频轨 |
| 上盖下 | 叠加轨盖住主视频 |
| 音画可解绑 | 默认联动，可拆开单独剪 |
| 所见即所导 | canvas 合成器预览导出共用 |

## 时间轴分层

从上到下：

| 轨 | 放什么 | 状态 |
| --- | --- | --- |
| 文字 | 标题、字幕 | 做 |
| 调节 | 无素材；盖在画面上的调色 / 暗角 | 做 |
| 叠加视频 / 图片 | 画中画、贴图 | 做 |
| 主视频 | 故事主线 | 做 |
| 原声 | 主视频自带音频，默认跟画面锁 | 做 |
| 配音 | 旁白，独立轨 | 做 |
| 音乐 | BGM，可淡入淡出、可循环 | 做 |
| 音效 | 短音效、卡点 | 做 |

## 操作

| 操作 | 怎么用 |
| --- | --- |
| 导入 | 素材箱导入，拖到对应类型的轨；双击按类型落到默认轨。视频进主轨时自动带原声 |
| 切割 | Ctrl+K 切选中段；Ctrl+Shift+K 切开所有轨；联动音画一起切 |
| 删除 / 波纹删 | Delete 留洞；Shift+Delete 或 Ripple 后面的段前移 |
| 拖边 | 改入出点 |
| 跨轨拖 | 主视频 ↔ 叠加；类型不对会拒绝 |
| 变换 | 检视里改位置、缩放、旋转、透明度；预览拖、滚轮缩放、Shift+滚轮旋转；可打关键帧 |
| 调节层 | 素材箱「调节」或时间轴拖长；无素材，盖在主视频+叠加上、文字之下；透明度是混合量 |
| 调色 | 主视频 / 叠加 / 调节：预设（黑白/暖/冷/褪色/鲜艳/胶片）+ 亮度、对比、饱和、暗角 |
| 转场 | 主视频片段：切 / 淡入淡出 / 叠化 |
| 字幕 | 文字轨打字，或导入 SRT。SIL OFL；导出默认不烧录 |
| 音量 | 整段音量 + 淡入淡出 + 音量关键帧；轨可静音 |
| 闪避 | 音乐默认在配音出现时压低 |
| 变速 | 整段 0.5x–2x，联动原声一起变 |
| 变速曲线 | 检视打变速点；时间轴浅色菱形。只改素材时间，不改片段长度 |
| 滤镜 | 顶栏「商店」调色 / 风格 / 镜头 / 社区；无选中片段时在播放头放调节层 |
| 花字 / 贴纸 | 商店里选样式或贴纸，落到文字轨 |
| 滤镜包 | 商店「滤镜包」导入导出 JSON，写入本机和当前工程 |
| 降噪 / EQ | 音频检视：降噪 + 低/中/高；预览导出同一混音 |
| 稳定 | 分析后再拉稳定量，补偿抖动 |
| 跟踪 | 对准目标后从播放头跟踪，写成位置关键帧 |
| 多机位 | 加机位，1–9 在播放头切角度 |
| 抠像 | 主视频 / 叠加：绿幕色键、相似度、边缘；预览导出同一 `drawFrame` |
| 嵌套 | 工作区「嵌套」（无工作区则播放头起 5 秒）；双击进入，退出回到根时间轴。最多套 3 层 |
| 倒放 | 检视勾选，音画一起倒 |
| 循环 | 音乐 / 音效勾选后，拖长片段会重复素材 |
| 磁吸 | 对齐播放头、其它片段边缘、标记 |
| 联动 | 默认 linked；检视里解绑 |
| 波形 | 原声 / 配音 / 音乐 / 音效片段画出素材波形，跟切入出点、变速、倒放、循环 |
| 标记 | M 或时间轴「标记」打在播放头；[ / ] 跳转；磁吸对齐；选中后 Delete |
| 素材预览 | 素材箱单击预听/预览，双击或「放到时间轴」；可替换当前选中片段 |
| 工作区 | I / O 入出点；预览可循环；导出可只出这一段 |
| 复制粘贴 | Ctrl+C / X / V，粘到播放头；联动原声一起带上 |
| 微移 | Alt+←→ 一帧，Alt+Shift+←→ 一秒 |
| 适配 | F 或「适配」让整条片子铺满时间轴窗口 |
| 预览 / 导出 | 同一 `drawFrame`；WebM / MP4。MP4 可选浏览器直录、本机 ffmpeg 或自动 |

快捷键：空格播放，← → 逐帧，I/O 工作区，M 标记，[ ] 跳标记，Ctrl+C/X/V，Alt+←→ 微移，F 适配，Ctrl+Z 撤销，Ctrl+D 复制到片段后，Ctrl+K 切开，C / V 切割与选择。

嵌套、滤镜、抠像、变速曲线、花字贴纸、降噪 EQ、稳定跟踪、多机位都走同一条 `drawFrame` / 音频调度。滤镜包是本机 JSON，没有在线社区后台。

## 工程文件

`project.json` 只存轨和片段引用（轨类型、入出点、变换、音量），`media/` 放素材。浏览器还会把工程写进 `localStorage`、素材进 IndexedDB。不要把视频写进 JSON。

浏览器导出仍走 MediaRecorder；桌面端若 PATH 里有 ffmpeg，选 MP4 会再转一刀 H.264。稳定和跟踪是画面相关算法的轻量实现，长素材分析会花一些时间。
